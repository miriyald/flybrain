One circuit, two jobs

The Drosophila mushroom body, built from the Janelia hemibrain connectome and run in your browser.

The point is not that a brain was simulated. It is that this circuit implements a computational trick — sparse random expansion coding — which computer science independently rediscovered as locality-sensitive hashing. Both demos below are the same 55 glomeruli and the same 1,927 Kenyon cells, wired exactly as the connectome measured them. Only the readout differs, and the readout learns by one rule: synapses that were active when dopamine arrived get weaker. Nothing is ever strengthened.

Recognition

Read a handwritten digit

Draw a digit and watch 1,927 Kenyon cells fire. Taught by punishing every wrong answer and rewarding the right one — the fly's two dopamine systems, both acting by depression.

pixels -> 55 glomeruli -> 1,927 cells -> 10 outputs 93.9% on held-out digits, from a rule with no gradient
 Control

Learn to play Dino

Harder: there is no label, only a crash — and it arrives long after the decision that caused it. The synapse holds a decaying tag, so dopamine can still find the moment to blame.

game state -> 55 glomeruli -> 1,927 cells -> 3 actions one fly, learning from its own deaths
